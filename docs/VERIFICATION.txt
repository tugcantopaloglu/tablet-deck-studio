NOT YET VERIFIED ON HARDWARE
Soundpad remote control is verified with an isolated named-pipe fixture, not a live Soundpad installation. Actual Soundpad playback, Discord keybind delivery, Discord screen sharing, and end-to-end audio routing require a rehearsal on the user's setup.
No Android tablet was connected during creation. APK installation, Android WebView behavior, tablet audio/touch/rotation, actual Wi-Fi routing, and physical USB connection still require a test on your device. OBS protocol tests used fixture data, not a live broadcast. The USB helper uses official ADB reverse support; its full tablet-to-PC path was not exercised here.

This app implements the documented streaming controls. It does not reproduce Elgato's proprietary plugin marketplace or every third-party integration.
