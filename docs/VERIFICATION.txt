REVIEW, INCIDENT AND LIMITS
- Fresh reviewer scored both P2s resolved and approved source/logic scope: human choosers/scans no longer inherit network deadlines; manual diagnostics reset on connection identity changes. Inherited Studio design documented; no replacement visual system.
- One failed-build test command accidentally started a stale companion against the default data directory and briefly opened the control panel. It was disclosed and stopped. Startup performed the normal backed-up profile/config migration, preserving existing actions and credentials. Subsequent runners guard build success, explicitly disable browser/tray and use isolated data. The companion now rejects unknown CLI options before accessing data or starting a server/window. No entirely GUI-free development-pass claim is made, and the incident was not visual/hardware verification.
- The passing isolated suites used synthetic OBS/Soundpad dependencies, fake foreground selection/key sinks and generated audio bytes; no real stream, recording, camera scan, app-picker dialog, foreground-app integration or user sound playback was exercised by them.
- Rendered fit, physical tablet touch, real keyboard/focus/screen-reader behavior, camera/permission UX, Wi-Fi/USB hardware rehearsal, live OBS/Soundpad/Discord audio routing, long-session stability and Voicemeeter remain unverified for these additions.
- Diagnostics measure network/loopback request timings, not end-to-end sound or broadcast latency, and do not estimate packet loss. Automatic editing locks expire after 12 seconds without renewal; stale profile saves are refused.
- Packs retain imported assets for backup references; deleting profiles does not remove those files. Soundpad native libraries, favourites, recent history and automatic rules are outside portable packs. Normal board backups include extra mixer inputs but not recent history/rules.
- Live video and Twitch/Kick chat previews are a later phase; no accounts or preview capture were connected. Windows binaries remain unsigned. Update both components and rehearse before broadcast use.
