SECURITY
- snyk_code_scan is unavailable; Snyk Code CLI scanned/rescanned first-party changes. No errors or warnings; informational notes are documented.
- Existing informational notes: bundled privileged WebView JavaScript and four loopback test TLS exceptions. New informational note: JavaScript enabled in the separate remote provider WebView. JavaScript is required by public chat; mitigation is isolation (no DeckNative), provider-only HTTPS resources, restricted navigation, normal certificate validation, no local files/content/downloads/intents and destruction while hidden. It is not suppressed or reported as a zero-finding scan.
- Provider pages never load in the main Android control WebView. PC remote frames cannot load top-level scripts into the console; selected-provider frame origins are explicit, and console/admin APIs retain auth/origin protections.
- Preview has a separate OBS client and Android worker, one capture at a time, maximum four attempts/s globally, 4s cancellation budget, at most 384KB JPEG data, and bounded dimensions. Failed/busy captures do not queue or replay controls. No frames are written to disk by the feature.
- Native Windows host keeps its top-level view on the exact local console origin/document, denies permission requests and exposes no native scripting bridge. External windows require user action and HTTPS. Local exports use an explicit Save dialog; remote downloads are blocked. NuGet vulnerability audit reported no vulnerable packages in its current sources.
- Update downloads use fixed official release filenames/URLs, normal HTTPS validation, GitHub SHA256 and byte counts. Windows also checks installer identity/version and embedded payload integrity. Helper validates the actual parent process/path, acknowledges readiness, waits for exit, confines writes to verified program paths, backs up/attempts rollback and preserves private board data. Android uses authorized selected USB only, checks version afterward, never uninstalls/clears data or requests downgrade, and respects opt-in reopening/automation. ADB and native helpers use structured arguments, not shell-composed commands.
- No account passwords, tokens, webhooks, automatic chat posting, user scenes/images, private data or third-party sound collections are included in release artifacts.
